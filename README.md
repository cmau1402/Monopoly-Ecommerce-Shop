# Monopoly Shop E-Commerce System
## Overview

The Monopoly Shop E-Commerce System is a full-stack web application developed as a semester-long database systems project at Montclair State University.

The application simulates an online retail store where customers can browse Monopoly-themed products, create accounts, purchase merchandise, and review previous orders. Employees have access to a secure administrative portal for inventory management, employee account creation, and order administration.

The project demonstrates database design, SQL programming, backend development, secure authentication, and CRUD operations.
